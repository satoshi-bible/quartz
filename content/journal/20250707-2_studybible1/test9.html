``` ### 解説 #### 1. CSSカスタムプロパティ（変数）の定義 スタイルシートの最初に`:root`セレクタを使って、線のスタイルを定義する変数をまとめています。 ```css :root { --header-footer-line-width: 0.5pt; /* 線の太さ */ --header-footer-line-style: solid; /* 線のスタイル (solid, dashed, dottedなど) */ --header-footer-line-color: #aaa; /* 線の色 */ } ``` - `--`で始まる名前がカスタムプロパティです。 - 後から線の太さを変えたい場合は、ここの`--header-footer-line-width`の値を `1pt` や `2px` などに変更するだけで、ヘッダーとフッター両方の線に適用されます。 #### 2. ヘッダーの線 (`@top-center`) ```css @top-center { content: ""; vertical-align: bottom; border-bottom: var(--header-footer-line-width) var(--header-footer-line-style) var(--header-footer-line-color); } ``` - `@top-center`は、ヘッダーの中央部分の領域です。ここに線を描画します。 - `content: "";`：ボーダーなどのスタイルを適用するには`content`プロパティが必須です。中身は空で構いません。 - `vertical-align: bottom;`：ヘッダー領域（ページの上部マージン）の**下端**に要素を配置します。これにより、線が本文のすぐ上に引かれます。 - `border-bottom: ...`：要素の下側にボーダー（線）を指定します。値には先ほど定義した変数を`var()`関数で呼び出して使っています。 #### 3. フッターの線 (`@bottom-center`) ```css @bottom-center { content: ""; vertical-align: top; border-top: var(--header-footer-line-width) var(--header-footer-line-style) var(--header-footer-line-color); } ``` - `@bottom-center`はフッターの中央領域です。 - `vertical-align: top;`：フッター領域（ページの下部マージン）の**上端**に要素を配置します。これにより、線が本文のすぐ下に引かれます。 - `border-top: ...`：要素の上側にボーダーを指定しています。 この方法により、すべてのページにヘッダー／フッターと本文を区切る線が自動的に描画され、そのデザインも一箇所で管理できるようになります。
